# Fork baseline (Phase 0)

Where the multiplayer fork starts: the upstream tree it branched from, what the retail tests say on the owner's install, and the logic timings
every later phase is measured against. Plan: phase 0 of the fork plan (P0 → P1 determinism → P2 MP soak → P3 parity ∥ P5 perf ∥ P6 render and
controls → P4 2.02 profile).

## How to re-run

```
python tools/fork/retail_check.py                      # everything; the summary goes to workspace/fork/retail/<time>/
python tools/fork/retail_check.py --tests "*test_fb7*" --no-godot
python tools/fork/upstream_sync.py                     # what upstream has that the fork lacks, and whether a merge conflicts
```

Both need the MSVC environment (`vcvars64`) and `ROTWK_INSTALL`, `BFME2_INSTALL` (and `GODOT` for the Godot steps), as `run_tests.bat` does.
